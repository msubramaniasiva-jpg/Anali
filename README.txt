===============================================================
  ANALI TECHNERGIES - MOBILE APP BUILD PACKAGE
===============================================================

இந்த ZIP கோப்பில் உள்ளவை:
1. index.html       - முழுமையான மொபைல் அப்ளிகேஷன் குறியீடு
2. manifest.json    - PWA ஆப் விவரக்குறிப்பு
3. sw.js            - ஆஃப்லைன் சேவை இயக்கி (Offline Service Worker)
4. icon-192.png     - 192x192 மொபைல் லோகோ ஐகான்
5. icon-512.png     - 512x512 உயர் தெளிவுத்திறன் லோகோ ஐகான்

---------------------------------------------------------------
முறை 1: ஒரு நிமிடத்தில் நேரடி Android APK கோப்பாக மாற்றுவது
---------------------------------------------------------------
1. பிரவுசரில் https://www.appsgeyser.com தளத்திற்குச் செல்லவும்.
2. "Create App" -> "Business" -> "HTML / Zip App" என்பதைத் தேர்ந்தெடுக்கவும்.
3. இந்த 'Anali_Technergies_App_Package.zip' கோப்பை அப்படியே அப்லோட் செய்யவும்.
4. App Name: Anali Technergies
5. App Icon: ZIP-ல் உள்ள 'icon-512.png' ஃபைலைத் தேர்ந்தெடுக்கவும்.
6. "Build / Download APK" என்பதைக் கிளிக் செய்யவும்.
7. சில நொடிகளில் உங்கள் போனுக்கு Anali_Technergies.apk பதிவிறக்கம் ஆகிவிடும்!

---------------------------------------------------------------
முறை 2: வாழ்நாள் இலவச இணைய ஆப்பாக (PWA) மாற்றுவது (Netlify Drop)
---------------------------------------------------------------
1. https://app.netlify.com/drop தளத்திற்குச் செல்லவும்.
2. இந்த 'Anali_Technergies_App_Package.zip' கோப்பை அன்சிப் (Unzip) செய்து, 
   அனைத்து கோப்புகளையும் அந்தப் பக்கத்தில் உள்ள கட்டத்திற்குள் இழுத்துப் போடவும் (Drag & Drop).
3. உடனே உங்களுக்கு https://anali-tech.netlify.app போன்ற ஒரு நேரடி இணைய லிங்க் கிடைக்கும்.
4. அந்த லிங்கை உங்கள் போனில் திறந்தால், போன் தானாகவே "Install App" எனக் கேட்கும்!
